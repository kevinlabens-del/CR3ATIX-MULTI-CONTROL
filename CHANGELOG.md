# Journal des changements

## v0.1.0-alpha — 2026-09-27
- APK Android et Receiver Windows compilés par GitHub Actions et publiés pour essais.
- Receiver Android expérimental avec service visible, appairage TLS et gestes après consentement explicite.
- Mode contrôleur Android : touchpad, texte, clavier et souris physiques dans l'application, commandes vocales simples.
- Site GitHub Pages affichant uniquement les binaires réellement présents.
- Moteur géométrique FOLLOW avec quatre tests automatiques, non encore relié à la capture physique.

La V1 complète n'est pas encore disponible ni validée sur matériel.
