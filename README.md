# CR3@TIX MULTI CONTROL

## État du projet

Développement en cours. Aucune V1 utilisable ni APK n'est encore publiée. Le dépôt est actuellement privé : une page GitHub Pages publique exige une configuration de visibilité et de Pages adaptée.

## Objectif

Contrôle local explicite de plusieurs appareils Android et Windows, avec appairage, interface tactile, clavier et souris physiques, puis espace FOLLOW. Aucun contrôle furtif ni exposition Internet prévue.

## Validation requise

La compilation et les essais physiques avec Redmi 10C, TCL 306, Galaxy Tab A SM-T510 et Windows restent indispensables avant toute annonce de V1. Le passage LOCAL ↔ DISTANT global dépend des restrictions de capture d'entrée Android et ne peut pas être certifié à partir du code seul.

Consultez [le plan et les limites techniques](docs/VALIDATION.md).
